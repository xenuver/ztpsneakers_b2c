# 📸 Screenshot Directory

Letakkan screenshot halaman aplikasi ZTP Sneakers di folder yang sesuai.

## Struktur Folder

```
screenshots/
├── storefront/              ← Halaman customer-facing
│   ├── 01_homepage.png
│   ├── 02_katalog.png
│   ├── 03_detail_produk.png
│   └── 14_profile.png
│
├── admintoko/               ← Panel Admin Toko (staf)
│   ├── 01_dashboard.png
│   ├── 02_products.png
│
└── jasmine/                 ← Jasmine Dashboard (owner)
    ├── 01_dashboard.png
```

## Petunjuk

- Format file: `.png` atau `.jpg`
- Resolusi yang direkomendasikan: **1280×800px** atau lebih tinggi
- Ambil screenshot dalam kondisi sudah ada data (gunakan `seed.py` terlebih dahulu)
- Gunakan **browser fullscreen / zoom 100%** untuk konsistensi tampilan
